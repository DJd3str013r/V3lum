# Contract additions - WP20 (wave 4)

Reports v2: TLP 2.0 markings everywhere, a CSP-hashed self-contained HTML report with a sidecar hash,
the honest first screen in every medium, licence / disclosure / engagement sections, grouped rows
and the standalone manual-pivot page (P336, P311, P377, P322, P302, P335, P146, P258, P324, P329;
A1, A2, A7, A8, A10, A11; AR03, AR13, AR14, AR17, AR24). No name of the frozen guide is renamed and
no documented module behaviour changes: modules keep writing plain strings, findings, attributes and
links, and the renderers decide how they are shown.

Who needs it: **module authors** (section "What module authors can rely on"), **WP13/WP18/WP21**
(`write_reports` records the files itself; `misp` and `pivots` formats), **WP25** (header line from
`case['meta']['tls_interception']`), **WP29** (attributions come from the notice fragments).

## Details

### Files (`write_reports`)

```text
<out_dir>/20261126-101500-ab12.TLP-AMBER.html          0600
<out_dir>/20261126-101500-ab12.TLP-AMBER.html.sha256   0600  "<sha256 hex>  20261126-101500-ab12.TLP-AMBER.html\n"
```

* The TLP label comes from the case (`summary.tlp_value`: unreadable -> RED, nothing recorded -> AMBER).
* With `record=True` the report **and sidecar** paths and their SHA-256 go to `Store()` (default case
  DB): `cases purge` removes them (their names contain the case id), `cases verify` recomputes them.
  App.scan and `cases report` need no change; `commands.cases.record_reports` may still record them
  again (idempotent).
* At TLP:CLEAR/GREEN every format is written from `summary.shareable_view(case)` (no `sightings`
  attribute, no `case_sightings` finding, no `recurrent_infrastructure` correlation, no
  `internal_sightings`; internal-sighting findings keep title and severity without their reference).
* JSON: top-level `tlp` first; the raw values of CPF (every punctuation form), VIN, personal-form
  EU VAT, PIX key/BR Code, payment-card and secret entities/seeds are replaced by their masked display
  everywhere in the document unless `show_personal` (default: the flag recorded in `case['options']`).
* Every format is rendered before the first file is written: a renderer failure leaves no file
  behind. Files written before a later write failure (disk full) are still recorded, then the error
  propagates.
* `misp` calls `report.misp.event(case)` (WP21); `pivots` writes `report.pivot_page.render(case)`.
  The pivot page is written only when `pivots` is requested (add it to setting `report_formats` to
  get one per scan).

### HTML report

CSP meta with the script hash, no-referrer meta, no `src`/`url()`/`@import`/fonts/images; the only
script is `html.JS`. Marking: header badge with the TLP 2.0 definition, a marking at the top of every
`<section>` (plus the engagement banner of LIGHT/ACTIVE cases), footer, `@page` margin boxes and a
fixed print-only badge. Footer: attributions in a collapsed `<details>`, then
`summary.CONTENT_END_MARKER`, then the hash note (SHA-256 of every byte before the marker).

Sections (ids): `bottom-line`, `attention`, `your-assets`, `correlations`, `findings`, `entity-map`,
`entities`, `timeline`, `pivots`, `coverage`, `appendix-licence`, `appendix-disclosure`, `evidence`,
`notes`. The `coverage` section of a LIGHT/ACTIVE case also lists every target touched with its
request count and every out-of-scope refusal with its reason (A7; the header shows the first ten).

### Links (P311 cond 5/8, P336 cond 2-3, A2)

| link | TLP:CLEAR/GREEN | TLP:AMBER, AMBER+STRICT | TLP:RED |
|---|---|---|---|
| pivot-pack template (`ref`), third-party host | clickable (`rel="noreferrer noopener"`) | defanged text + 'opening sends <value> to <host>' | omitted (`v3lum links` only) |
| touches_target (declared, or the investigated/hostile host) | defanged text + warning; collapsed (expand) for hostile entities | same | omitted |
| module `res.link` (no template) | clickable only to an allow-listed documentation host (`REFERENCE_HOSTS`) | same, and only when the URL carries no case value | omitted |
| finding `references` | same rule as module links | same | same (references are not pivots) |
| privacy link (person, phone, e-mail) | only with `show_personal` | same | omitted |
| any non-http(s) URL (`javascript:`, `data:`, `file:` ...) | dropped (counted) | dropped | dropped |

Attribute values never become links. Entity values are masked (CPF, VIN, personal-form EU VAT) and
defanged when hostile and for URLs; URLs inside module free text are defanged.

* A pack link (`ref`) whose URL host differs from its declared `host` is treated as a plain module
  link (never clickable as a template; the warning names the URL's real host).
* Privacy links are shown only for analyst-typed seeds, and only with `show_personal` (P311 cond 6).

### Markdown

First line `**TLP:<LABEL>**`, then the TLP 2.0 banner (and the engagement and licence banners); every
`##` section starts with the marking. Module text is backslash-escaped (no raw HTML, no injected
links), URLs and e-mail addresses inside it are defanged (no autolinks). POSSIBLE identity links are
only counted (listed in the HTML details).

* Values in code spans have `|` escaped (`\|`): GFM splits table cells at a bare pipe before it
  parses code spans, so a value such as `a|[x](https://evil)` can never open a cell with a live link.
* Hosts of the disclosure ledger are code spans; engagement refusal lines, sighting lines and pivot
  labels/notes go through the defanging text path: a `www.`/`http` target is never autolinked.
* The content-end marker occurs exactly once: a value quoting it is shown as
  `<!-- quoted:v3lum:content-end-->`.

### Attributions (P336 cond 6)

Generated, never typed: notice fragments (`v3lum/data/notices/*.json`) whose `files` name the source
file of a module that answered (ok/empty) - or whose `name` is a dataset the runs cited -, the
dataset registry's `attribution`, `PROVIDER_ATTRIBUTIONS` for providers whose answers were used, and
MITRE ATT&CK when an ATT&CK id appears.

## What module authors can rely on

* **Attribution**: list your module file (and data files) in your notice fragment's `files`, or set
  `register_dataset(..., attribution=...)`: the report credits the source whenever your module
  answered or your dataset was cited. Nothing to add in module code.
* **Breach/infostealer findings**: tag them `breach`, `infostealer`, `credential_exposure` or
  `stealer_log` and keep `data_classes` and the P145 `password_form` in the finding data (top level or
  per record under `breaches` / `records` / `breach_records`): reports print 'data classes: ...' and
  'passwords: hashed (bcrypt)' in plain words. A value that is not a password-form word is never
  printed.
* **Clickable links**: only pivot-pack templates are clickable (and only at TLP:CLEAR/GREEN). A
  `res.link(...)` URL is shown as defanged text with the disclosure warning unless its host is an
  allow-listed documentation host; to offer a clickable pivot, ship a pivot-pack template.
* **Grouping**: findings stating the same fact about the same subject (same breach, URL variants,
  same CVE; see `core.grouping`) are one display row 'seen by N sources'; every finding keeps its
  id, evidence and feedback. Case JSON and exports are never grouped.
* **Your assets**: findings with `ownership='own_asset'` (or tag `own_asset`) are listed first in
  their own section.
* **Internal sightings**: the attribute `internal_sightings` (`[{platform, ref, tlp, verdict, ...}]`)
  is shown as 'known internally: MISP event #N, ...' (hits above the case TLP left out; nothing at
  TLP:CLEAR/GREEN).
* **TLS interception** (WP25): `runtime.meta['tls_interception'] = {intercepted, issuer, profile,
  checked_at, host}` gives one header line in every medium.

## Hand-offs (files WP20 does not own)

* `v3lum/commands/cases.py` (WP18) `record_reports(..., audit=True)`: the audit list comprehension
  calls `os.fspath(path)` on every value of `written`, including the `'_errors'` list that
  `write_reports` returns when recording failed - a TypeError after the files were written. Skip
  values that are not `str`/`os.PathLike` (as the hash loop above it already does).

* `tests/test_permissions.py` (WP10): `test_reports_are_never_written_outside_out_dir` asserts the
  wave-2 name `v3lum-<id>.json`; with A2 file names it must read
  `.endswith("20261126-120000-ok01.TLP-AMBER.json")`.
* `v3lum/config.py` (setting `report_formats`): add `pivots` to the default to write the manual-pivot
  page with every scan (P311 cond 11), if the team wants it by default.
