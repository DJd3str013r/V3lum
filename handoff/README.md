# Handoff material

Planning and tracking material from the build sessions, copied here so a later session can continue.
Paths written as `<scratch>/...` in these files map to this folder:

| path in the files | here |
|---|---|
| `<scratch>/impl/core/plan.json` | `handoff/plan/plan.json` |
| `<scratch>/impl/specs/` | `handoff/specs/` |
| `<scratch>/impl/modules/<batch>.json` | `handoff/manifests/<batch>.json` |
| `<scratch>/impl/providers_seed/owners.json` | `handoff/providers_seed/owners.json` |
| `<scratch>/impl/core/carry/`, `contract_notes.md` | `handoff/carry/` |
| `<scratch>/impl/core/wave*_reports.json`, `wave*_integration.json` | `handoff/reports/` |
| `<scratch>/impl/prep/<batch>/` | `handoff/prep/<batch>/` (notes and parsers only, for the batches not yet implemented) |
| `<scratch>/impl_tools/` | `handoff/tools/` |

`handoff/PROMPT.md` is the continuation prompt (Portuguese). Remove this folder before a release.
