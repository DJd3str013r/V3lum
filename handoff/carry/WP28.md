Exact fix, keeping the documented v1 fetch(name, url) call (contract freeze): (1) datasets.py: change `DataStore.scoped(self)` to `scoped(self, *, http=None)`, then `DataView.__init__(self, store, http=None)` stores self._http. Add a keyword `http=None` to DataStore.fetch (and the fetch_text/json/lines wrappers) and forward it to `_download(..., http=http)`. In _download use `http = http if http is not None else self._dataset_http(reg, url)`. Registered datasets keep the reviewed datasets scope. (2) context.py line ~536: `self.data = runtime.data.scoped(http=self.http)`. The module's ScopedHttp then refuses ad-hoc URLs exactly like ctx.http: PolicyError (SKIPPED 'policy') for undeclared hosts and for disclosure 'none', the scope binding for ACTIVE, and the egress profile. Then drop the strict xfail on tests/safety/test_policy_hosts.py::test_a_disclosure_none_module_cannot_download_ad_hoc_data and tests/safety/test_scope.py::test_an_active_module_cannot_reach_out_of_scope_through_ad_hoc_data (WP28 part B drops them if WP04/WP08 have not).
