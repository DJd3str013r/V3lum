### Final conditions (binding spec - implement every item)

1. Split (architect floor). tor_exit_local: check.torproject.org/torbulkexitlist as a 1 h dataset matched through the shared IP index (P034), disclosure 'none', allowed at TLP:RED. tor_onionoo: Onionoo details?search=, disclosure third_party.
2. Non-Tor IPs never leave the machine: tor_onionoo queries only IPs that matched the local exit list or the locally matched Onionoo running-relay summary (a dataset). search= matches prefixes, so filter the exact IP client-side. Onionoo contact fields (operator e-mails/names) are dropped at ingestion.
3. Historical check, only when the IOC carries a date: CollecTor exit-lists (and the mthcht Tor history, MIT) as monthly archives through the core safe_extract helper (in-memory tar/xz, member and size caps, no extraction to disk), indexed locally ip -> timestamps from the tordnsel format (ExitNode / Published / LastStatus / ExitAddress).
4. CollecTor/mthcht archives larger than 5 MB are fetched by `v3lum data update` (with a first-run hint), never in the middle of a scan (A6 BR9); a month that is not downloaded reads 'history not downloaded (run v3lum data update)', never 'not an exit'.
5. The historical answer prints the date checked and the source ('was an exit on 2026-11-20, CollecTor'). dan.me.uk is not used.
6. Severity: is_tor_exit alone = LOW context with tag anonymizer and the note 'Tor exit: traffic from many users, no attribution possible', never malicious and never higher without other evidence (CR28). Non-exit relays = info. ATT&CK T1090.003 is mapped when an IOC IP is a Tor exit.
7. The bulk exit list's age is shown; older than 6 h it is refreshed, otherwise the result is could-not-verify. Onionoo uses If-Modified-Since. ExoneraTor is a manual pivot link. Tor Metrics attribution (CC0/CC BY) in THIRD_PARTY_NOTICES.md.
8. Tests with the recorded bulk-list and Onionoo fixtures, a CollecTor archive slice, a stale-list case and an exact-IP filter case.

Chair rationale: Approved 6-0 at median P1. The architect's floor splits the local check from the Onionoo lookup so TLP:RED keeps the exit check, drops dan.me.uk and bounds archives. osint_investigator: no non-Tor IP is sent to a third party (the chair adds the locally matched relay summary so non-exit relays still show, as analyst_ux asked). legal_dpo: Onionoo contacts dropped, attribution. analyst_ux: LOW context severity and the dated historical answer. Tor Project public data: tier trusted, terms open.

Synthesizer conditions (background; the final conditions win on conflict): Download check.torproject.org/torbulkexitlist hourly (matched locally) -> is_tor_exit; Onionoo details?search= for relay flags/nicknames/first_seen; CollecTor exit-lists for historical 'was it an exit on date X' (for log/IOC dates). Notes: Feeds CR28 anonymized_infrastructure; essential for log/IOC triage.
