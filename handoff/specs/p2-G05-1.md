### Final conditions (binding spec - implement every item)

1. Module username_social/bluesky (disclosure third_party, opsec passive). Hosts public.api.bsky.app and plc.directory only. Endpoints: app.bsky.actor.getProfile, com.atproto.identity.resolveHandle, app.bsky.actor.searchActors and plc.directory/{did}/log/audit.

3. Inputs: analyst-typed usernames (run_on='seeds'), normalised to {u}.bsky.social when there is no dot; bsky handle/profile URLs (P333 bsky_handle); domains, via resolveHandle(domain) -> DID -> profile, emitted as an 'official account' pivot.
4. Status: HTTP 400 {'error':'InvalidRequest','message':'Profile not found'} = ABSENT (presence absent, Status.EMPTY); any other 400 (invalid handle syntax) = SKIPPED reason_code 'not_applicable'; 429, 5xx and timeouts = could not verify (rule 5). Fixtures: found, missing, invalid syntax, handle.invalid.
5. 'handle.invalid' = POSSIBLE. checked_at is recorded because handles can be transferred.

7. PLC audit log capped at 200 entries and stored only as (handle, PDS endpoint, date) tuples, shown as a dated timeline. Previous handles belong to the same DID and become username pivots with expand=False, fed to username_check only on analyst confirmation.
8. searchActors runs only for analyst-typed keyword/domain seeds: top 10 shown as 'candidate accounts named like X', POSSIBLE, expand=False, never identity links. A verified custom-domain handle becomes a domain pivot for passive modules only. Handle history is case-bound (retention_days).

Chair rationale: Approved 6-0 at median P2. Consolidated: the architect and redteam_lead forbid fetching .well-known/atproto-did or did:web documents (direct contact with a subject-controlled host = LIGHT); osint_investigator, the architect and analyst_ux require that only a verified, DID-consistent custom-domain handle counts as CONFIRMED and that searchActors results stay candidates; cti_lead asked for the check date; legal_dpo keeps handle history case-bound.

Synthesizer conditions (background; the final conditions win on conflict): public.api.bsky.app getProfile/resolveHandle/searchActors (400 'Profile not found' = absent); custom-domain handles are verified by the domain owner -> CONFIRMED link to that domain; plc.directory/{did}/log/audit -> previous handles and PDS endpoints with dates.
