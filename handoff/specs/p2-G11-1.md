## P293 `orkl` - ORKL CTI report library

- council: **approved**, priority P2, default_enabled=False, provider_tier=unknown, terms=unknown, opsec=passive, shares_input=True
- category: cti_framework; group: G11; inputs: threat_actor, malware_family, keyword, cve; produces: url
- auth: none; key env vars: -; hosts: orkl.eu

### Final conditions (binding spec - implement every item)

1. Legal floor (A1): ORKL publishes no terms readable from the research egress (JS-only site), so terms='unknown': the module runs in no profile until legal records the terms in the provider registry. No unknown-terms source is default at release, so default_enabled=False.
2. Tier (A8): unknown until the registry reviewer records otherwise. While unknown it is excluded at TLP:AMBER+, runs at CLEAR/GREEN only with --allow-unknown, and receives only IOC_TYPES values (cve, mitre_technique); threat_actor and malware_family queries need a recorded promotion to community tier. Victim company names are never sent.
3. Queries: library/search?query=&limit= with limit <= 10, min_interval 1 s, cache 7 days. Error fields inside HTTP 200 bodies -> ERROR; timeouts and errors = could not verify (rule 5).
4. Output: report title, publisher, date and URL as links (terminal shows the 5 most recent, HTML up to 10). No PDF or report-file download; excerpts truncated (publishers keep copyright).
5. IOC extraction from report plain_text is off by default; with an explicit option the text is truncated first and IOCs are tagged 'from report <title> (<date>)', low confidence, warninglist-filtered (P169) and never verdicts (reports carry example and benign IOCs).
6. Merge gate (A16): offline tests with FakeHttp (unmatched requests fail, network guard active) over trimmed real fixtures without personal data (the captured search response plus an empty result), a provider-registry entry for every host, the registry contract test and the P327 lint.

Chair rationale: Approved 6-0 at median P2 (legal_dpo voted P3). legal_dpo's floor classifies the terms as unknown and the operator as unknown tier, so under A1/A3/A8 it cannot be default and stays off until legal records the terms; A8 also limits an unknown-tier operator to IOC values until promoted. cti_lead's and analyst_ux's input limits, link-only output and opt-in report IOCs, and the architect's bounds, are the spec.

Synthesizer conditions (background; the final conditions win on conflict): library/search?query=&limit= -> report titles, sources, dates, linked actors; links only (report files hosted by publishers).
Notes: Finds public CTI reports mentioning an actor, malware or CVE.
