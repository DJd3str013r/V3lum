- council: **approved**, priority P2, default_enabled=True, provider_tier=n/a, terms=open, opsec=passive, shares_input=False

### Final conditions (binding spec - implement every item)

1. Ship data/pivot_links/domain_dns.json in the frozen P311 pack schema (label, template, entity_types, category, host, verified, checked_at, privacy, publishes=false, touches_target, login_required, antibot). The pack is offline data (disclosure 'none'): V3LUM never requests these URLs or any API behind them.
2. Rendering follows A2/P311: at TLP:AMBER and above every link is non-clickable text with 'opening sends <value> to <host>'; at RED third-party links are hidden from reports and listed only by `v3lum links` with the warning; links are never auto-opened and `links --open` at AMBER+ needs an interactive confirmation naming the host.
3. CI renders every template with a sample value per declared entity type and with hostile values (quotes, spaces, unicode, newlines): each result must be an https URL on the declared host, built only from whitelisted placeholders through the declared encoder (never str.format, never {raw} in URL position).
4. Every link host has a provider-registry entry with tier and rationale (A8); unknown-tier hosts get the 'unknown operator' badge and their templates take IOC_TYPES values only (A8 BR4): never PERSONAL_TYPES, CNPJ, company names, keywords, malware or actor names, or other free text (P311 lint).
5. Initial host tiers for the registry reviewer to confirm: trusted - crt.sh (Sectigo), DNSViz (Sandia/Verisign Labs), Verisign DNSSEC Debugger, MXToolbox, dmarcian, DomainTools, whois.com; community - CompleteDNS, host.io, Whoxy, intoDNS, who.is.
6. Order: P311 groups links by analyst question with verified links first; inside a group the pack's file order is the curated analyst-value order (crt.sh, DNSViz, Whoxy and host.io history, MXToolbox and dmarcian first, then CompleteDNS, DomainTools, intoDNS, Verisign, who.is, whois.com); the terminal shows at most 8 links per seed, the rest go to HTML and `v3lum links`.
7. Verified links carry checked_at; `v3lum doctor --links` (offline) lists unverified links and links not re-checked for more than 180 days. The pack ships in phase 1 with the other pivot packs (A16), whatever the state of the related automated modules.
8. Entries (domain): CompleteDNS NS history page (never its /dns-history/ajax/ endpoint), crt.sh HTML search, DNSViz, host.io, Whoxy WHOIS/history, dmarcian DMARC Inspector, DomainTools reverse IP and WHOIS, intoDNS, MXToolbox SPF (dmarc: and mx: actions too), Verisign DNSSEC Debugger, who.is, whois.com.
9. cert_fingerprint: the crt.sh certificate lookup by SHA-256 renders only for 64-hex SHA-256 fingerprints; no template for other fingerprint forms unless verified.
10. Flags: pages that make the provider query the target's DNS live (intoDNS, MXToolbox, dmarcian, Verisign debugger) are touches_target=true and follow P311 (defanged, non-clickable warning, hidden for hostile entities unless expanded). The DNSViz label warns that its 'Analyze' button runs and publishes a fresh analysis.
11. whois.domaintools.com served a CAPTCHA to automated clients: antibot=true, verified by browser only, ranked last in its group. No template points to a page that lists recent lookups publicly (publishes must be false).

Chair rationale: Approved 6-0 at median P2 (osint_investigator and analyst_ux voted P1). It is pure data for the P311 engine, so it follows that schema; the architect's CI rendering test with hostile values and cti_lead's stale-link check are kept. cti_lead's scan-trigger concern maps to P311's touches_target and publishes flags; analyst_ux's curated order is the pack's file order inside P311's verified-first grouping. Host tiers are stated per A8; the pack itself sends nothing (tier n/a, terms open, default-on per A3 as manual links).

Synthesizer conditions (background; the final conditions win on conflict): Write data/pivot_links/domain_dns.json with the verified templates (CompleteDNS history, crt.sh HTML incl. SHA-256 lookup, DNSViz, host.io, Whoxy, dmarcian, DomainTools, intoDNS, MXToolbox SPF, Verisign DNSSEC debugger, who.is, whois.com); manual-only links (V3LUM never fetches them), grouped by entity type, verified ones listed first.
