### Final conditions (binding spec - implement every item)

1. These templates live in the topic packs (data/pivot_links/<topic>.json) with verified != 'curl', in the frozen P311 schema plus the optional per-link max_tlp field that the phase-0 schema must include. The packs are offline data (disclosure 'none'): V3LUM never requests these URLs, not even from doctor, and never solves their challenges.
2. Rendering follows A2/P311: at TLP:AMBER and above every link is non-clickable text with 'opening sends <value> to <host>'; at RED third-party links are hidden from reports and listed only by `v3lum links` with the warning; links are never auto-opened and `links --open` at AMBER+ needs an interactive confirmation naming the host.
3. CI renders every template with a sample value per declared entity type and with hostile values (quotes, spaces, unicode, newlines): each result must be an https URL on the declared host, built only from whitelisted placeholders through the declared encoder (never str.format, never {raw} in URL position).
4. Every link host has a provider-registry entry with tier and rationale (A8); unknown-tier hosts (e.g. archive.today, hunter.how) get the 'unknown operator' badge and receive IOC values only.
5. Initial tiers (reviewer confirms): trusted - VirusTotal, Shodan, Censys, SecurityTrails, Cloudflare Radar, ICANN, Internet Archive, abuse.ch, AbuseIPDB, Talos, OTX, X-Force, Kaspersky (RU), Spamhaus, Hybrid Analysis, Joe Sandbox, MetaDefender, NVD, Exploit-DB, Meta; community - Netlas, Spur, CentralOps, DNSlytics, dotDB, TGStat, tellows, CVEdetails, Vulners, Ahmia, Arkham, Chainabuse.
6. Verification: verified takes 'curl', 'browser' (a dated one-time manual check by a team member) or false. Browser-verified links count as verified in the P311 ordering, so VirusTotal, AbuseIPDB, Shodan, OTX, Talos, abuse.ch and Wayback rank first; markers read '(browser)' or '(may show a challenge)'. The terminal shows at most 8 links per seed.
7. Rule 7: search/view/report pages only. VirusTotal uses /gui/file/{hash}, /gui/domain/{d}, /gui/ip-address/{ip} and /gui/url/<sha256 of the URL> (vetted placeholder); Wayback calendar or URL list, never /save; archive.ph capture lists, never /submit.
8. VirusTotal, Hybrid Analysis, Joe Sandbox, Filescan and MetaDefender templates are never upload or rescan pages; the lint rejects upload, submit, save and rescan paths. CentralOps Domain Dossier never carries the svc_scan option (it port-probes the target; unit test on the template string).
9. Pages that require a login (e.g. Shodan search) are excluded by the P311 lint; host and report pages that work without login stay. Ahmia stays a manual link only (its scripted search needs a per-session anti-bot token, rule 1).
10. Kaspersky OpenTIP: badge 'foreign provider (RU) - check the company vendor policy' and max_tlp=clear, so it is hidden by default and listed only by `v3lum links` (redteam_lead, legal_dpo, analyst_ux).
11. Personal-data templates (tellows for phone, TGStat for username, e-mail pages) are privacy=true: analyst-typed seeds only, opt-in per case, trusted/community hosts only (A8). Under the corporate profile VirusTotal stays manual-only (public API excluded, A1/A15).
12. Also routed here: the challenge-walled explorers of P216 (Etherscan, BscScan, Tronscan, Arkham, Chainabuse), Meta Ad Library (BR scam ads) and CVE reference pages (CVEdetails, Vulners, NVD, Exploit-DB search). `v3lum doctor --links` lists browser-only links due for re-check (> 90 days). Ships in phase 1 (A16).

Chair rationale: Approved 6-0 at median P2 (cti_lead, osint_investigator and analyst_ux voted P1). Every member stressed rule 7 (no submit, save, upload or rescan deep links) and never fetching or solving challenges; the architect added that doctor never touches them. analyst_ux's 'browser-verified' status lets the analysts' top tools rank first without breaking P311's verified-first ordering. redteam_lead's and legal_dpo's CentralOps and Kaspersky conditions are adopted, and osint_investigator's privacy rule and routed entries complete the pack.

Synthesizer conditions (background; the final conditions win on conflict): Store in the same pivot packs with verified=false; render after verified links with an 'unverified (opens in browser; may require login/challenge)' badge; V3LUM never fetches them and never tries to solve their challenges; re-verify periodically from an analyst browser (doctor command lists them).
Notes: Many top analyst tools (VT, OTX, Shodan) are SPAs or behind Cloudflare but still valuable manually.
