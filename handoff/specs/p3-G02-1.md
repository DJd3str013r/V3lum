## P037 `netlas` - Netlas host/domain API

- council: **approved**, priority P3, default_enabled=True, provider_tier=community, terms=noncommercial, opsec=passive, shares_input=True
- category: ip_network; group: G02; inputs: ipv4, domain, keyword; produces: domain
- auth: free_key; key env vars: V3LUM_NETLAS_KEY; hosts: app.netlas.io

### Final conditions (binding spec - implement every item)

1. Registry access modes: keyless and the free Community plan = noncommercial (Netlas pricing FAQ: 'for your own personal needs (non-commercial use only)', checked 2026-11-26); a paid plan key = key-terms. Off under the corporate profile until licence-cleared: it runs only with key_plans.netlas='business' or a licence_allow entry.
2. Requires key 'netlas' in config.KNOWN_KEYS (V3LUM_NETLAS_KEY as alias), sent only in the X-API-Key header. Default runs happen only with a key; without one the module reports NEEDS_KEY. Keyless calls exist only through explicit -M where the licence profile allows them, under a daily_quota.
3. Host and domain endpoints of app.netlas.io; use the free count to size a job before spending quota. Daily budget through the P334 block; seeds first.
4. Error bodies inside 200 are mapped through P321 markers (QUOTA, RATE_LIMITED, NEEDS_KEY), never EMPTY.
5. domains[] on CDN/shared-hosting IPs (P034) are reported as counts only; co-hosted domain pivots are capped and expand=False on shared IPs.
6. The web UI is behind a Cloudflare challenge: manual pivot link only (A9).
7. Trimmed real fixtures for the host and domain endpoints (the anonymous host fixtures exist).

Chair rationale: Approved 6-0 at median P3 (cti_lead and redteam_lead voted P2). osint_investigator found Netlas' own wording that the free plan is non-commercial; legal_dpo's floor requires a company account on a business-compatible plan, so the chair classes keyless/Community use as noncommercial and lets the module run under corporate only with a recorded paid plan (stricter than cti_lead's 'once terms are recorded'). analyst_ux: default only with a key. The architect's floor: header auth, quota, error mapping, real fixtures. Netlas is a commercial provider whose terms page returned 404 during the council: tier community until reviewed.

Synthesizer conditions (background; the final conditions win on conflict): Host endpoint answered keyless (rate-limited); optional V3LUM_NETLAS_KEY for domains_count/download; daily request budget.
Notes: Alternative scan data source with WHOIS/DNS enrichment.
