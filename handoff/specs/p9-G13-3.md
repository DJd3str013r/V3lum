## P285 `path_discovery` - Common API/admin path discovery (bounded) with SecLists wordlists

- council: **approved**, priority P3, default_enabled=False, provider_tier=n/a, terms=open, opsec=active, shares_input=False
- category: pentest_recon; group: G13; inputs: domain, url; produces: url
- auth: none; key env vars: -; hosts: github.com
- sources shared with other proposals: {"C0650": ["P370"]}

### Final conditions (binding spec - implement every item)

1. ACTIVE gate (A7): runs only with --mode active, a non-empty --authorized REF and a --scope FILE on every path (scan, run, shell, watch, batch; non-interactive runs refuse without both), on scope-file matches only after resolution and per redirect hop, never on pivots or on entities extracted from text/files; CDN/shared-hosting/SaaS IPs excluded unless listed.
2. A7 ceilings enforced by the core client and socket connector: <= 10 requests/probes per second and <= 2 concurrent connections per target host, the case ACTIVE budget, the kill switch (traffic stops within 2 s), proxy_active egress profile (A13), the hostile-host guard, and every request in the hash-chained P324 ledger; the report banner carries REF, scope SHA-256, window and egress.
3. One forced-browsing engine shared with P279 (soft-404 calibration with random paths, content signatures, redirect-to-login = miss, P321 challenge detection): one engine, two lists. Passive equivalents (archived and urlscan paths) are absorbed first (P376).
4. Lists: a curated default list of <= 50 paths pinned in data/active.lock (OpenAPI/Swagger, GraphQL endpoint/UI, Spring actuator index, common admin panels). SecLists (MIT) only with an explicit --wordlist, <= 5,000 entries (A7), pinned by SHA-256 and fetched by `v3lum data update`, at <= 5 req/s per host.
5. GET/HEAD only; stop the host at the first 429 or challenge. Detection by status, content type, title, length and the first 1 KB; only paths whose response differs from the calibrated baseline are reported, with a count of paths tested. Stored: status, content type, title and length.
6. Forbidden (A7): actuator heapdump/env/logfile/threaddump/configprops are recorded as present, never downloaded; no GraphQL introspection; no calls to discovered API operations; no login attempts or brute force on found panels.
7. Results are tri-state (confirmed / not observed / could not test): blocked egress, a proxy, 403/429, a challenge or a timeout is 'could not test', never closed, absent or safe (rule 5). Merge only after the AR20 safety suite passes (A16). Results are url entities with expand=False.
8. Tests use a loopback HTTP server with soft-404, login-redirect and panel fixtures, and assert the 50-path default and the wordlist cap.
9. Licences (A6): the default list is V3LUM-authored from public documentation; theHarvester's GPL-2.0 API-prefix list is study material only and is never copied into data/.

Chair rationale: Approved 6-0 at median P3. The A7 floor (legal_dpo, redteam_lead) applies. Of the default list sizes proposed (50, 100, 200) the chair takes redteam_lead's 50, the strictest, plus the architect's 5 req/s for wordlists and his single forced-browsing engine shared with P279. redteam_lead's line between recon and access (no actuator dumps, no introspection, no logins) and analyst_ux's baseline-difference reporting are adopted. Scheduling (A16 BR1): P3 with effort M, so it is not built in this build; BACKLOG.md keeps this spec as the unblock target.

Synthesizer conditions (background; the final conditions win on conflict): Active+authorized; small curated list by default (API docs, swagger/openapi, graphql, actuator, admin panels), SecLists (MIT) only on explicit --wordlist with rate caps; soft-404 calibration with random paths; results as url entities (expand=False).
Notes: Finds exposed APIs/admin panels on owned sites.

## P286 `port_scan` - TCP connect port scan (top-N) + banner grab

- council: **approved**, priority P3, default_enabled=False, provider_tier=n/a, terms=open, opsec=active, shares_input=False
- category: pentest_recon; group: G13; inputs: ipv4, ipv6, domain; produces: cve
- auth: none; key env vars: -; hosts: -

### Final conditions (binding spec - implement every item)

1. ACTIVE gate (A7): runs only with --mode active, a non-empty --authorized REF and a --scope FILE on every path (scan, run, shell, watch, batch; non-interactive runs refuse without both), on scope-file matches only after resolution and per redirect hop, never on pivots or on entities extracted from text/files; CDN/shared-hosting/SaaS IPs excluded unless listed.
2. Port scans additionally need a per-run interactive confirmation listing the targets (non-TTY runs refuse). Targets must be IPs/CIDRs listed in the scope file itself: a scoped domain resolving to a CDN/SaaS/shared IP (P378 third_party_hosted) is not in scope; private, loopback, link-local, CGNAT, ULA and metadata ranges are refused unless listed.
3. A7 ceilings enforced by the core client and socket connector: <= 10 requests/probes per second and <= 2 concurrent connections per target host, the case ACTIVE budget, the kill switch (traffic stops within 2 s), proxy_active egress profile (A13), the hostile-host guard, and every request in the hash-chained P324 ledger; the report banner carries REF, scope SHA-256, window and egress.
4. Scan limits: TCP connect only (sockets from the core connector, asyncio inside the worker thread), top-100 ports by default from own port-order data (facts only), top-1000 maximum, no UDP; <= 100 connection attempts/s in total (A7) and <= 50 sockets overall; one host or a /29 per run unless the scope file allows more.
5. Banners: read-only, <= 1 KB within 3 s, only for server-first protocols, no payloads sent; HTTP(S) ports are handed to web_fingerprint (P072) and tls_inspect (P275) instead. No service probes, logins or default-credential tries (A7).
6. Per-port tri-state: open (connect), closed (RST), filtered (timeout = unknown). A proxied or HTTPS-only egress, or blocked raw TCP, is 'could not test', never 'closed'. Open ports are listed with banners; closed and filtered ports are summarised as counts.
7. No CVE mapping here: version-based matching belongs to P291 with its 'version-inferred' confidence caps, never CRITICAL alone. Passive data (InternetDB, Shodan/Censys under their licence gates) stays the default answer and runs first (P376).
8. doctor and the run banner warn when proxy_active is not configured: a dedicated scanning egress is recommended so the corporate IP is not blocklisted (redteam_lead). The audit trail records REF, scope SHA-256 and targets (Codigo Penal art. 154-A, provider AUPs).
9. Tests use loopback listeners (open, closed, silent ports) and a proxied-egress case; merge only after the AR20 safety suite passes (A16).

Chair rationale: Approved 6-0 at median P3 (redteam_lead and legal_dpo voted P2). redteam_lead calls it the riskiest module in the build: his IP-level scope rule, interactive confirmation, banner limits and dedicated-egress advice are adopted together with the A7 floor (legal_dpo) and its ceilings, the stricter values winning (2 connections per host). The architect's tri-state and no-CVE-mapping rules and the 'could not test, never closed' semantics every member asked for complete it. Scheduling (A16 BR1): P3 with effort M, so it is not built in this build; BACKLOG.md keeps this spec as the unblock target.

Synthesizer conditions (background; the final conditions win on conflict): Only with --mode active --authorized + interactive confirmation + scope file (assets, owner, signer, ticket, expiry) and audit log; asyncio connect scan of top-100 ports (nmap-services order), concurrency/rate caps, banner read <= 1 KB with timeout; HTTPS-only proxies block raw TCP -> 'could not test' (never 'closed'); InternetDB remains the passive default.
Notes: Confirms exposure of owned assets (CR13/CR14) when passive data is stale.

## P287 `public_docs_discovery` - Public-document discovery for a domain (metagoofil-style)

- council: **approved**, priority P3, default_enabled=False, provider_tier=trusted, terms=key-terms, opsec=light, shares_input=True
- category: pentest_recon; group: G13; inputs: domain; produces: url, username, person_name
- auth: mixed; key env vars: V3LUM_SEARCH_API_KEY; hosts: web.archive.org, archive.org
- sources shared with other proposals: {"C0144": ["P059"]}

### Final conditions (binding spec - implement every item)

1. Passive discovery first through the Wayback CDX client shared with P059 (mimetype filters for pdf, doc(x), xls(x), ppt(x)) and the Common Crawl index; documents come preferably from Wayback raw captures (web.archive.org/web/<ts>id_/<url>), which keeps this part PASSIVE.
2. Save Page Now is never used (rule 7). Legal records internal CTI research as the purpose under the Internet Archive terms; volume stays low (rule 6).
3. Search fallback only when the archives return nothing, and only through P307's Brave Search source under its veto_lift (no SerpApi or other CAPTCHA-solving SERP service, rule 1), its per-case query budget and TLP gate; search engines are never scraped. Brave is key-terms, so this module's class is key-terms.
4. Live download from the target only through the shared LIGHT file fetcher: --mode light, analyst-typed seed domains only (never pivots), P376 egress and hostile-host guard, core address guard, <= 10 documents, <= 10 MB each and <= 20 MB in total, <= 1 req/s, P324 ledger; content type and magic checked with P270.
5. Documents are parsed only by the P269 functions in the shared sandbox. The case keeps metadata and SHA-256; the file itself only if the analyst marks it as evidence. Metagoofil (GPL-2.0) and PyMeta (GPL-3.0) are study material only; nothing is copied (A6).
6. Minimisation (legal floor, A5): usernames and person names are kept only for org_profile (verified) or in-scope domains, as attributes aggregated to counts plus <= 5 samples inside the case, expand=False, never auto-checked by username or e-mail modules. For third-party domains only software, internal paths and counts are kept.
7. Output aggregated: number of documents, unique authors/usernames count, software versions, internal paths. Opt-in (default_enabled=False). Tiers: Internet Archive, Common Crawl and Brave trusted.
8. Merge gate (A16): offline tests with FakeHttp (unmatched requests fail, network guard active) over trimmed real fixtures without personal data (the CDX/availability captures plus synthetic documents), a provider-registry entry for every host, the registry contract test and the P327 lint; the LIGHT download step waits for the AR20 safety suite (A16 BR6).

Chair rationale: Approved 6-0 at median P3 (osint_investigator and redteam_lead voted P2). osint_investigator, redteam_lead and the architect keep it passive through archive raw copies, with LIGHT target downloads only as a bounded, ledgered step on typed seeds. legal_dpo's floor removes SerpApi (via P307's veto_lift) and limits personal data to own or in-scope assessments, which is close to cti_lead's own-domains rule; the smallest size caps proposed are taken. analyst_ux's aggregate output is the presentation. Scheduling (A16 BR1): P3 with effort M, so it is not built in this build; BACKLOG.md keeps this spec as the unblock target.

Synthesizer conditions (background; the final conditions win on conflict): Search via a keyed search API (SerpApi) or archives/urlscan for site:{domain} filetype:pdf|docx|xlsx|pptx (never scrape search engines); download at most N documents (default 10, size cap) from the target in light mode and pass to document_metadata; personal data in metadata -> minimise. Gap fill: keyless passive document discovery first: Wayback CDX url=*.{domain}/* with filter=mimetype:application/pdf (and docx/xlsx/pptx mimetypes) and the Common Crawl index (both reset from the research egress: verify from the team network); search APIs (P307) only when CDX finds nothing.
Notes: Leaks internal usernames/software via public documents.
